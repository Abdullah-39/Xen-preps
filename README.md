# xen-perps-frontend

XEN Perps: a XEN-branded perpetual futures front end on top of Hyperliquid. See [CLAUDE.md](CLAUDE.md) for the full architecture and rules.

## Run it

Requires Node >= 22.12 (for `@nktkas/hyperliquid`).

```bash
cp .env.example .env         # fill in BUILDER_ADDRESS / BUILDER_FEE from Saif
npm install
npm run dev                  # http://localhost:3000; the backend's SIWE_DOMAIN and CORS expect this port
```

Run `xen-perps-backend` on port 3001. Without a builder address and fee, market data still loads, but the trade panel shows a configuration error instead of the order form.

Checks: `npm run typecheck`, `npm run lint`, `npm run build`.

## Layout

| Path | What |
| --- | --- |
| `src/config/env.ts` | Public env vars, validated; network always comes from `NEXT_PUBLIC_HL_NETWORK` |
| `src/config/bridge.ts` | Arbitrum USDC bridge addresses per network (from Hyperliquid's docs) |
| `src/lib/api.ts` | XEN backend client (nonce, SIWE verify, terms) |
| `src/lib/hl/clients.ts` | Hyperliquid HTTP/WebSocket transports, `InfoClient`, `SubscriptionClient` |
| `src/lib/hl/trading.ts` | **The only place that calls `order`**: `placeOrder` always attaches XEN's builder code |
| `src/lib/hl/agent.ts` | Agent key generation and storage, in the browser only |
| `src/lib/hl/orderMath.ts` | Decimal order maths, tick/lot rounding, market-order slippage price |
| `src/lib/hl/hooks.ts` | Market, order book, account and open-order data (snapshot plus live WebSocket) |
| `src/features/auth` | SIWE sign-in and JWT session (cleared on account switch or 401) |
| `src/features/terms` | Terms status and acceptance |
| `src/features/onboarding` | `TradingProvider`: the step gate (connect → network → sign in → terms → deposit → enable trading). Builder fee and agent approval |
| `src/features/deposit` | USDC transfer to the bridge |
| `src/features/trade` | Markets, order book, order form, positions and open orders |

## Notes

- `next.config.ts` aliases `@x402/*` to an empty module. They are optional peer deps of `@coinbase/cdp-sdk`, which wagmi's Base Account connector pulls in. We don't offer that connector, because it is a smart wallet.
- `AGENTS.md` is generated by `next dev`. Leave it.
